Git and GitHub Workflow

Each assignment is developed using Git feature branches and GitHub pull requests.

The workflow includes:

1. Creating a feature branch from main.
2. Making changes and adding the required documentation or configurations.
3. Staging changes using git add.
4. Committing changes using meaningful commit messages.
5. Pushing the feature branch to GitHub.
6. Creating a pull request for review.
7. Merging approved changes into main.
8. Verifying the updated repository.
